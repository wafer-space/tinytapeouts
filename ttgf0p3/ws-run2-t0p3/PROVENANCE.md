# Provenance of tinytapeouts/ttgf0p3/ws-run2-t0p3

[Tiny Tapeout GF 0p3](https://tinytapeout.com/chips/ttgf0p3) is a [Tiny Tapeout](https://tinytapeout.com/) chip: 32 projects, each in one or more tiles, behind a multiplexer that selects one project at a time, with the multiplexer, controller and pads around them. It was made as slot T0P3 of the wafer.space GF180MCU Run 2 shuttle (G802, [ws-run2](https://github.com/wafer-space/ws-run2)).

# How This Repository Was Generated

- `layout/` is the die exactly as it is on the G802 reticle: the `T0P3_tt_gf_wrapper_<column>_<row>` cell cut from the reticle in [ws-run2](https://github.com/wafer-space/ws-run2) with its seal ring and fill, moved to the origin. Cell names keep the reticle's `$N` suffixes.
- It matches the precheck output of the Tiny Tapeout release [`tapeout-ws2607`](https://github.com/TinyTapeout/tinytapeout-gf-0p3/releases/tag/tapeout-ws2607) (`tt_gf_wrapper.oas.tt_gf_wrapper.precheck.*.output.*`) on every layer and in every project placement. The one difference is that on the reticle the dummy COMP layer (22/4) is merged into COMP (22/0); the shape counts match exactly.
- `data/shuttle_index.json` is the release's `shuttle_index.json` unchanged. It lists each project's multiplexer address, tile position and size, source repository and commit. In `data/manifest.csv` and the README the repository URLs are normalised to `https://` (no `git@` form, `.git` suffix or trailing slash).
- `data/tt_shuttle.json` gives the dates shown in the shuttle status: when submissions closed (`end_date` in the shuttle repository's `config.yaml`) and when the release [`tapeout-ws2607`](https://github.com/TinyTapeout/tinytapeout-gf-0p3/releases/tag/tapeout-ws2607) was published. It is written by `ws-run-reports tt-manifest`.
- `data/manifest.csv` has one row per project: `CODE` is the multiplexer address, zero-padded to three digits, `TOP` the project's `tt_um_*` macro, `SLOT_SIZE` its size in tiles. It is written by `ws-run-reports tt-manifest` ([ws-run-reports](https://github.com/wafer-space/ws-run-reports)); `FLOW_VERSION` (LibreLane) and `PDK_VERSION` (open_pdks commit) come from each project's `pdk.json` and are empty where it does not record them. `LICENSE_FILE` and `DOCS_FILE` give the project's `LICENSE` and `docs/info.md` in the shuttle repository, and are empty where the project has none. Title, author, description, language and clock come from `projects/<macro>/info.yaml` in [tinytapeout-gf-0p3](https://github.com/TinyTapeout/tinytapeout-gf-0p3/tree/305047697e4931a74c12202dfc83e1946b9685d9) at `305047697e`, the commit the release was built from.
- `images/T0P3.svg` draws each project's outermost placement in the layout; `images/T0P3.png` is rendered from the layout with `scripts/lay2img.py` and `reticle.lyp` from [reticle-stitcher](https://github.com/wafer-space/reticle-stitcher) (`--width 4096 --oversampling 4`), the same way as the ws-run images.
